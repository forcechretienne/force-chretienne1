# Force Chrétienne + Joyau

Application web mobile (PWA) réalisée par ZEMA Technologies.

- `index.html`, `app.js`, `app.css` : l'application
- `config.js` : adresse et clé publique de la base Supabase
- `manifest.webmanifest`, `sw.js`, `icons/` : installation sur téléphone
- `vendor/` : bibliothèques (Preact, htm, Supabase)
- `supabase/schema.sql` : structure de la base de données (à exécuter dans Supabase > SQL Editor)

Hébergement : Vercel, sans étape de compilation (Framework preset : Other).
